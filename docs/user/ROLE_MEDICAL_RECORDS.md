# Medical Records — User Guide

For staff who register patients, manage visits, appointments, and operational reports.

**Quick start:** [EMR_USER_QUICK_START_GUIDE.md](EMR_USER_QUICK_START_GUIDE.md) · **Workflow:** [VISIT_LIFECYCLE.md](../workflows/VISIT_LIFECYCLE.md)

## Typical sidebar modules

- Medical Records (dashboard)
- Register Patient
- Manage Patients
- Patient Records (lookup)
- Create Visit
- Appointments
- Referrals
- Reports

Exact labels depend on your role configuration.

## Daily tasks

| Task | Path |
|------|------|
| New patient | Medical Records → Register Patient |
| Find / edit patient | Manage Patients or Patient Records |
| New visit | Create Visit |
| Appointments | Appointments |
| Reports | Reports (attendance, clinic statistics, etc.) |

## Registration tips

- Choose the correct **category** (employee, dependent, non-NPA, etc.) — ID format depends on it.
- Complete **required** demographics before saving.
- Use **search** before creating duplicates.
- Photo upload is optional unless policy requires it.

## Visits & appointments

- Link every visit to the correct patient.
- Set clinic, date, and time; confirm visit type.
- For follow-ups, search existing patient rather than re-registering.

## What you usually cannot do

- Clinical orders (lab, Rx) — consultation module.
- Vitals entry — nursing module.
- User administration — admin module.

Request extra pages from your administrator if your job requires them.

## Problems?

- **Cannot see module:** role pages need updating (admin).
- **Patient not found:** try patient ID or personal number; check inactive/merged flags with supervisor.
- **Save errors:** note field highlighted in red; contact support with screen URL.
