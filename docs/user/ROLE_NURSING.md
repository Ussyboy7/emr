# Nursing — User Guide

For nurses recording vitals, managing pool/room queues, procedures, and ward workflows.

**Quick start:** [EMR_USER_QUICK_START_GUIDE.md](EMR_USER_QUICK_START_GUIDE.md) · **Workflow:** [VISIT_LIFECYCLE.md](../workflows/VISIT_LIFECYCLE.md)

## Typical sidebar modules

- Nursing dashboard
- Pool / room queue
- Patient vitals
- Vitals history
- Procedures
- Wards (if admitted patients)

## Daily tasks

| Task | Path |
|------|------|
| Work incoming visits | Nursing → Pool / queue |
| Record vitals | Patient vitals (from queue or visit) |
| Review past vitals | Vitals history |
| Nursing procedures | Procedures |
| Ward care | Wards (when patient admitted) |

## Vitals

- Open the correct **visit** before recording.
- Enter plausible values; the system may validate ranges.
- Save before leaving the screen.
- Incomplete vitals may block consultation handoff — follow local policy.

## Queue workflow

- **Pending** → **Vitals** → **Ready for room** stages vary by site; use dashboard cards as source of truth.
- Do not start consultation from nursing screens unless your role includes consultation.

## What you usually cannot do

- Register new patients (records).
- Prescribe or sign consultations (doctors).
- Verify lab results (laboratory).

## Problems?

- **Visit missing from pool:** wrong date filter, visit cancelled, or consultation already completed.
- **Cannot save vitals:** check required visit link; confirm nursing vitals page on your role.
- **Slow queue:** refresh once; if persistent, report time and clinic to IT.
