# Laboratory Attendance Report Table Reorder — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reorder the patient-category row order in the laboratory attendance report (and matching reports) from:
**Officers, Staff, Employee Dependents, Retiree Dependents, Non-NPA, Retirees**
to the new order:
**1. Officer, 2. Staff, 3. Employee Dependent, 4. Retiree, 5. Retiree Dependent, 6. Non-NPA** (+ Medical Examination where it already applies — lab only).

**Architecture:** The row order is generated by one canonical helper, `mr_category_row_filters()` in `backend/reports/attendance_statistics.py:76`, consumed by the lab attendance, weekend duty, and observation-admissions reports. Reorder the canonical list to the new order so those three reports update together. Then update the reports that define their own hardcoded ordering (patient demographics, attendance summary, daily visit statistics, and frontend tables) matching the same new order.

**Tech Stack:** Django 4.2 + reports modules; Next.js 16 + React 18 + Tailwind; duplicates many per-report `categories` lists.

## Target Order (canonical)

Target rows, `sn` values in the new order:
1. Officers
2. Staff
3. Employee Dependents
4. Retirees
5. Retiree Dependents
6. Non-NPA
7. Medical Examination — **only in lab attendance** (module-specific extra row; not applicable to other reports)

Note the label variation across reporters: `Employee Dependents` vs `Employee Dependants`; `Non NPA` vs `Non-NPA`. Keep each file's existing label text; change order only.
